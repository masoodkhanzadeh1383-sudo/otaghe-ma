# اتاق ما — نسخه ۲

این نسخه ساختار آنلاین واقعی را دارد:

- ورود ناشناس Firebase
- ساخت/ورود به اتاق با کد
- چت لحظه‌ای با Firestore
- رویداد دلتنگی و بغل
- ثبت حال
- یادداشت مشترک
- آماده‌سازی Firebase Cloud Messaging برای اعلان واقعی
- Cloud Function برای فرستادن اعلان رویدادها به اعضای اتاق

## چیزی که هنوز باید تنظیم شود
1. در Firebase یک پروژه بسازید.
2. Android App با package name `com.otaghema.app` اضافه کنید.
3. فایل `google-services.json` را داخل پوشه `app/` قرار دهید.
4. Authentication > Anonymous را فعال کنید.
5. Firestore را فعال کنید.
6. Cloud Messaging را فعال کنید.
7. برای Functions، داخل `functions` دستور `npm install` و سپس deploy انجام شود.
8. برای اعلان، توکن FCM هر کاربر باید در `users/{uid}.fcmToken` ذخیره شود؛ در این اسکلت محل دریافت توکن آماده است و مرحله ذخیره‌سازی سروری باید تکمیل شود.

## نکته امنیتی
قوانین Firestore اینجا برای نمونه توسعه هستند و قبل از انتشار عمومی باید محدود شوند تا فقط اعضای همان اتاق بتوانند داده‌های اتاق را بخوانند/بنویسند.

## خروجی
پس از اتصال Firebase، پروژه را در Android Studio باز کنید و APK بسازید.
